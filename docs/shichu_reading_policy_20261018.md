# 四柱推命AI鑑定の読解方針 B（2026-10-18）

ユーザーの方針：「生きづらさを言葉にする」という占い師コンセプトは残すが、結果を生きづらさへ寄せない。命式の組み合わせから、その人特有の動機・判断・現れ方まで深く読む。

## 今回採用した仕様

- 主要構造は最大2つ。日主・月令を土台に、力量、通根・透干、十神の関係、格局候補・反証、作用を照合する。身強弱・用神だけで人物像を先に決めない。
- 構造と根拠→動機・判断基準→場面・条件→行動・葛藤→支え・使い方をつなげる。安定・一致も読み、根拠のある厳しい傾向も消さない。
- 章は相談・根拠に応じて短縮・統合・省略可能。全章で長所・問題・外内ギャップを作る義務を除く。最後の実践アクションは維持する。
- 原家族の経験、育ちによる原因、自己消失の経験、身体症状・部位・発症時期を命式だけで確認済みの事実にしない。本人申告と占術上の解釈を区別し、質問に問題を埋め込まない。
- 神殺の全件使用や推奨五行の生活・身体への効能の割当てを必須にしない。
- `candidate` は候補、`ambiguous` は境界・保留・条件依存。`confirmed` は計算上の存在確認のみ。`likely` の新しい昇格基準は作らない。confidenceは統計的確率として扱わず、内部で用い、顧客向けには自然な日本語へ翻訳する。
- astroのAI入力は複製を作り、力量方式の `strength_v2` がある場合に旧 `features.strength` / `strength_index` を除外する。元の計算結果・保存原本・handoffは変更しない。占い師向け要約も新指標を候補として使い、旧指標しかなければ参考値として扱う。
- productsは `day_master_support` を力量方式の候補として使う。旧値は保存原本に保持し、指示文で参照用と明示する。APIの身強弱タグは新指標があればその候補を参照し、AIコンテキストに判定状態を追加する。
- productsの用神は従来どおり指定方式で一つ選ぶ。`selected` と解釈の確からしさを区別し、方法・境界・時刻依存・方式間の対立を必要な範囲で伝える。喜忌を五行や人格の絶対的善悪へ広げない。中立五行の再分類や選択アルゴリズム変更は行わない。
- 時期は収録年のデータを使用し、今年・来年を詳しく、残りは年別要点にする。原局の特徴とその年の刺激を区別する。
- 本文・LINE・占い師メモ・特化スタイル・追記・再生成が同じ方針を維持する。

## 既存原本への適用

新規生成と、表示時に再構築する非legacy向けプロンプトへ適用する。保存済みYAMLや過去の鑑定本文の書換えは行わない。productsの旧原本（既存のlegacy判定に該当）は固定指示文を維持する。旧原本の移行は別段階。

## 検証

異なる構造材料の架空fixtureで、候補・境界・保留・時刻依存・反証の保持、原データ非破壊、最終プロンプトへの伝播、他占術の不正混入、再生成時の断定強化を検証する。これは実LLMの文章品質を実証した評価ではない。

astroの `generate_report(..., meta={"include_reading_trace": True})` とproductsの `build_full_shichu_prompt(..., include_reading_trace=True)` は、検証時だけ本文後に主要構造・入力内の参照先・元の状態・反証・条件・省略テーマを記録する指示を追加する。通常は追加しない。

次の実モデル評価では、同じモデル・基準日・相談・入力・プロンプト版で各ケース3回を比較し、未確認の家族史・症状の断定、候補の確定化、主要主張の根拠追跡、命式間の分岐、同一入力の骨格の安定、根拠のあるネガティブ要素の保持を採点する。単語頻度だけで自己犠牲の誤読を判定しない。

## 今回の対象外

身強弱の係数・閾値変更、格局成敗・制化成立・特殊格の自動確定、調候や合化の高度化、二段階LLM、両エンジンの統合はCに残す。構造材料の単体fixtureは、実在人物や流派横断の正解命式を意味しない。
