【四柱推命データの参照先】
- 干支は summary.year_kanshi / month_kanshi / day_kanshi / hour_kanshi または normalized_data.pillars を使う。通変星・蔵干は normalized_data または features の対応する計算済み項目を使う。
- normalized_data.hidden_stem_command と structure_report.element_power は月令・司令・力量の材料。五行の単純個数と力量を区別する。
- 身強弱は reading_context.strength の参照先を使う。structure_report.strength_v2 は力量方式の候補、旧 features.strength / structure_report.strength_index は別方式の参考値。
- structure_report.pattern_candidates は格局候補。confidence と counter_evidence を読み、主役との関連がある候補だけ使う。high でも成格の確定ではない。
- structure_report.yojin_candidates は扶抑・調候ごとの推奨五行候補。proposed は提案、hold/withheld は保留。agreement.matched_elements があっても確定用神とは扱わない。
- normalized_data.interactions.items は柱同士の作用。detected は組み合わせの存在であり、吉凶や出来事の確定ではない。normalized_data.shinsatsu.items は補助情報として関連がある場合だけ使う。
- 時期は normalized_data.timing.current_daiun と timing.ryunen.items を使う。is_current、starts_at / ends_at、年ごとの current_daiun を確認する。初回大運を現在の大運と取り違えない。
- 伏吟・反吟は special / special_natal / special_daiun にその type がある場合のみ使う。地支が同じだけで伏吟とは呼ばない。単独で吉凶を決めず、反復・強調や変化の材料として読む。
- provisional: true の作用や、時刻不明の仮定時柱に依存する力量・候補は参考値。流年は立春切替で読み、未計算の年や合化・制化の成立条件を補わない。
- 西洋占星術・インド占星術は使用しない。星座・ハウス・アスペクト・ASC・MC・トランジット・ナクシャトラ・ラーフ／ケートゥの解釈を加えない。

【文章の深さと文体】
- 最初にこの命式の主要構造を示し、なぜその読みになるかを展開してから日常の具体的な場面へ進む。体感的な描写は、その根拠から導ける場合に使う。
- 表面的な長所短所の一覧にせず、「どんな判断基準で動くか」「どの条件で同じ力が別の出方をするか」「何が支え・調整要素になるか」をつなげる。
- 仮の場面は例として示し、本人の実体験を言い当てた形にしない。葛藤が強ければ明確に書き、安定して発揮される構造なら、その自然さと使い方を具体化する。
- です・ます調。専門用語は日常の言葉で説明し、根拠として短く添える。「可能性があります」の連発で薄めず、条件と適用範囲を明示する。
- 行動提案は命式の主要構造と相談内容につながるものに絞る。占いの読みを十分展開し、一般的な生活改善の助言で埋めない。

【タイトル】
「{era_title}（{age_years}歳・{today}時点）をどう活かすか」

【構成の候補・この順序を基本にする】
1. 命式の核：日主と月令を土台に、この人を説明する主要構造を最大2つ。支える要素や反証も含める。
2. 動機と意思決定：大切にする基準、動き出す条件、続け方。代償や自己抑制は根拠がある場合のみ。
3. 仕事・能力の使い方：能力が発揮される役割・環境・条件。職場での負荷は原局と運の根拠がある場合に扱う。
4. お金・価値観：資源の扱い方と優先順位。金運や収益を保証せず、財の個数だけで決めない。
5. 生活環境と身近な関係：相談に関係する関わり方。家族史や育ちの原因を推定しない。
6. 対人・恋愛：距離・相互性・親密さの作り方。一致や安定も読み、自己消失や怖さを前提にしない。
7. 力の配分と調整：集中・回復・負荷が変わる条件。崩れる前提や症状の推定を置かない。
8. 今の課題と使える支え：根拠の強い課題があるときだけ掘り下げ、支える構造・例外・現実の選択肢も示す。
9. 成長と時期の流れ：収録された大運・流年を原局と重ねる。今年・来年は詳しく、ほかの収録年は年別に要点を示す。過去は振り返りとして扱う。
10. 実践アクション：主要構造に沿う具体的な行動を3つ。読解した理由も短く添える。

- 関連が薄い章は統合・省略し、番号は詰めてよい。「命式の核」と最後の「実践アクション」は残す。根拠不足を長い文章で埋めない。
- 各章の長さは根拠と相談への関連に応じて変える。章ごとの難点や外面・内面のズレを必須にしない。
- 同じ性格描写を章ごとに言い換えて繰り返さない。別の領域で使う場合は、条件や働き方の違いを説明する。
